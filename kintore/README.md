# 自重ノート（自重トレ＆ストレッチ記録アプリ）

Expo (React Native) 製の iPhone 向けアプリ。腕立て伏せとスクワットを中心にした自重トレーニングと、ストレッチの記録・ガイドができます。記録はすべて端末内に保存され、アカウントもサーバーも不要です。

## 機能

- **すぐ記録**: ホームの「腕立て伏せ」「スクワット」から1タップで記録開始。今日の合計回数も表示
- **トレーニング記録**: セットごとに回数（プランクなどは秒数）を記録。前回の値を表示し、初期値として自動入力
- **休憩タイマー**: セット完了で自動スタート（±15秒、スキップ、終了時にローカル通知）
- **ストレッチガイド**: 種目ごとの秒数をカウントダウンし、左右も含めて自動で次へ進む。一時停止・スキップ可。全身／上半身／下半身の3メニュー入り
- **やり方の解説**: 全ストレッチと腕立て伏せ・スクワット・プランクに、棒人形のイラスト（効く部位を強調）、効く場所、手順、コツを表示。「動画で見る」で YouTube の検索結果を開く
- **自己ベスト**: 1セットの最大回数（最長時間）の更新を自動検出
- **種目**: 腕立て伏せ・スクワットのバリエーション、体幹、ストレッチなど約60種目＋カスタム種目
- **分析**: 腕立て・スクワットの累計、週ごとの回数、合計回数、ストレッチ時間、部位別セット数、体重の記録
- 週の目標回数と連続達成週数、データの JSON 書き出し

## 開発

```bash
cd kintore
npm install
npx expo start        # QR を iPhone の Expo Go で読むと実機で確認できる
npm run typecheck
npm test              # 計算ロジックのユニットテスト
npx expo export --platform web   # dist/ に Web 版を出力（ブラウザでの動作確認用）
```

構成: `src/app/`（画面・Expo Router）、`src/components/`、`src/lib/`（`store.ts` が状態と永続化、`calc.ts` が計算）。

## App Store へのリリース手順

Mac は不要です（EAS のクラウドでビルド・提出します）。必要なのは次の 2 つのアカウントです。

1. **Apple Developer Program**（年 99 USD）: https://developer.apple.com/programs/enroll/
2. **Expo アカウント**（無料枠で可）: https://expo.dev/signup

ターミナルで:

```bash
cd kintore
npx eas-cli@latest login
npx eas-cli@latest init                       # Expo プロジェクトを作成し app.json に projectId を追記
npx eas-cli@latest build --platform ios --profile production --auto-submit
```

途中で Apple ID のログインを求められます。証明書やプロビジョニングプロファイル、App Store Connect 上のアプリ登録は EAS が自動で行います。完了すると TestFlight にビルドが届きます。

その後 [App Store Connect](https://appstoreconnect.apple.com) で次を入力して「審査へ提出」します。

| 項目 | 内容 |
| --- | --- |
| 名前 | 自重ノート - 腕立て・スクワット記録（同名が取られていたら変更） |
| サブタイトル | 腕立て・スクワット・ストレッチを記録 |
| カテゴリ | ヘルスケア／フィットネス |
| プライバシーポリシー URL | https://futosi.github.io/eiga/kintore/privacy.html （このブランチを main にマージすると公開される） |
| App のプライバシー | 「データを収集しない」 |
| 年齢制限 | 4+ |
| 価格 | 無料 |
| スクリーンショット | `store/screenshots/` の 5 枚（6.9 インチ用 1320×2868） |
| キーワード | 自重,腕立て伏せ,スクワット,筋トレ,ストレッチ,記録,トレーニング,体幹,プランク,宅トレ |

説明文:

```
自重ノートは、腕立て伏せやスクワットなどの自重トレーニングと、ストレッチをかんたんに記録できるノートです。

■ 1タップで記録
ホームの「腕立て伏せ」「スクワット」からすぐ記録を開始。前回の回数が最初から入っているので、チェックを付けるだけで記録できます。

■ ストレッチをガイド
首・肩・背中・もも・ふくらはぎなど、部位ごとの種目を秒数のカウントダウンに合わせて順番にガイド。左右の切り替えも自動です。

■ 休憩タイマー
セットを完了すると自動でカウントダウン。アプリを閉じていても通知でお知らせします。

■ 成長が見える
腕立て・スクワットの累計回数、週ごとの合計回数、ストレッチ時間、自己ベストをグラフで確認。

■ 安心
アカウント登録は不要。記録はすべて端末の中だけに保存され、広告もトラッキングもありません。
```

### リリース前に確認してほしいこと

- `app.json` の `ios.bundleIdentifier`（`com.futosi.jijuunote`）は一度リリースすると変更できません。
- 実機（Expo Go または TestFlight）で一通り触って、休憩タイマーの通知が届くことを確認してください。開発時の動作確認は Web 版で行っており、通知・バイブ・画面スリープ防止は実機でしか確認できません。
